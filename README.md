## ✨ Features

- 💰 **Transactions** — income & expenses with categories
- 📊 **Budget tracking** — monthly limits per category
- 🏆 **Savings Goals** — targets with deadlines and progress
- 🎨 **8 themes** — 5 dark + 3 light, switch instantly
- 🌐 **Bilingual** — Persian (فارسی) & English with live RTL/LTR
- 📅 **Jalali & Gregorian** date formats
- 💱 **Multi-currency** — USD, EUR, Toman, Rial
- 🔒 **PIN lock** — SHA-256 hashed, 5-attempt limit
- 🎬 **Smooth animations** — splash, page slides, count-up, toasts
- 💾 **Backup & Restore** database
- 📤 **CSV + Excel export**
- 🎯 **JUnit 5 test suite**
